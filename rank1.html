Nothing is saved yet. Until you set CONFIG.rsvpEndpoint, this form only shows a notice. To collect replies in Google Sheets:

  1. Create a Google Sheet, then Extensions > Apps Script.
  2. Paste the code below and save.
  3. Deploy > New deployment > Web app. Execute as: Me. Who has access: Anyone.
  4. Copy the Web app URL into CONFIG.rsvpEndpoint at the top of the script. 
function doPost(e) {
  var sh = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var p = e.parameter;
  sh.appendRow([new Date(), p.name, p.attendance, p.guests, p.wishes]);
  return ContentService.createTextOutput('ok');
}

Optional: set CONFIG.whatsapp (digits only, with country code) to also show a "Reply on WhatsApp" button that works with no backend.
